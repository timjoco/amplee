Amplee Theme Builder

Design color themes for band public pages

How to use this tool

1. Pick a preset to start, or build from scratch
2. Adjust colors - the preview updates live
3. For gradients, paste CSS gradient code (or use a solid color)
4. When done, click "Export JSON" and send the file to Tim

Tip: Use cssgradient.io to create gradients!
